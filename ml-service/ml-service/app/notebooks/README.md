# Notebooks de Machine Learning

Esta carpeta contiene los notebooks utilizados durante el desarrollo del módulo de Machine Learning de VitalMind AI.

## Propósito

Documentar de manera ordenada y reproducible el análisis, la preparación, el entrenamiento y la evaluación de los modelos.

## Contenido esperado

- Análisis exploratorio de datos.
- Validación de calidad.
- Limpieza y preparación.
- Selección de variables.
- Ingeniería de características.
- División de conjuntos.
- Entrenamiento de modelos.
- Ajuste de hiperparámetros.
- Evaluación.
- Comparación de resultados.
- Interpretación.
- Selección de modelos.

## Convención sugerida de nombres

~~~text
01_analisis_exploratorio.ipynb
02_preparacion_datos.ipynb
03_clasificacion_riesgo.ipynb
04_pronostico_bienestar.ipynb
05_recomendador_bienestar.ipynb
06_analisis_emocional.ipynb
07_deteccion_anomalias.ipynb
08_comparacion_modelos.ipynb
09_serializacion_modelos.ipynb
~~~

## Estructura recomendada de cada notebook

1. Título.
2. Objetivo.
3. Descripción de los datos.
4. Importación de librerías.
5. Carga de datos.
6. Validación.
7. Preparación.
8. Entrenamiento.
9. Evaluación.
10. Gráficas.
11. Interpretación.
12. Conclusiones.

## Reglas

- No dejar celdas sin ejecutar cuando se entregue el notebook.
- Evitar rutas absolutas.
- Utilizar rutas relativas.
- Explicar cada gráfica.
- Documentar decisiones.
- Evitar código duplicado.
- Mover funciones reutilizables a `utils/`.
- No entrenar con el conjunto de prueba.
- No mostrar datos sensibles.
- Mantener un orden lógico de ejecución.
