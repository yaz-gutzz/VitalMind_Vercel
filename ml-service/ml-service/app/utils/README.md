# Utilidades de Machine Learning

Esta carpeta contiene funciones reutilizables para el procesamiento y análisis de datos.

## Contenido esperado

- Limpieza de datos.
- Validación de rangos.
- Codificación de variables.
- Escalamiento.
- Ingeniería de características.
- Carga y guardado de archivos.
- Funciones de evaluación.
- Preparación de entradas para los modelos.

## Objetivo

Evitar duplicar código dentro de los notebooks y mantener el proceso de Machine Learning organizado y reproducible.
