# Reportes de detección de anomalías

Esta carpeta contiene los resultados de los modelos utilizados para detectar cambios drásticos en la rutina.

## Contenido esperado

- Casos detectados como anómalos.
- Proporción de anomalías.
- Variables relacionadas.
- Puntajes de anomalía.
- Gráficas.
- Comparación entre algoritmos.
- Interpretación de casos.
- Falsas alarmas identificadas.

## Reglas

- No presentar una anomalía como diagnóstico.
- Analizar cada resultado dentro de su contexto.
- Documentar los umbrales utilizados.
- Explicar las limitaciones de los algoritmos.
