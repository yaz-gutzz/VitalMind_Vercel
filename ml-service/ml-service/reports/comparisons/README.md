# Comparación de modelos

Esta carpeta contiene las tablas y reportes utilizados para seleccionar los modelos finales.

## Contenido esperado

- Algoritmos evaluados.
- Hiperparámetros.
- Métricas.
- Tiempo de entrenamiento.
- Tiempo de predicción.
- Interpretabilidad.
- Estabilidad.
- Limitaciones.
- Justificación de selección.

## Reglas

- Comparar modelos con los mismos conjuntos.
- No seleccionar únicamente por una métrica.
- Considerar utilidad, estabilidad e interpretación.
- Registrar la versión de cada experimento.
- Explicar claramente la decisión final.
