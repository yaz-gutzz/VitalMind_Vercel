# Reportes del sistema de recomendación

Esta carpeta contiene los resultados del motor de recomendaciones de bienestar.

## Contenido esperado

- Recomendaciones generadas.
- Perfiles utilizados.
- Variables de similitud.
- Distancias o similitudes.
- Pruebas con distintos usuarios.
- Evaluación de coherencia.
- Casos en los que no se genera una recomendación.

## Reglas

- Explicar por qué se recomienda cada elemento.
- Evitar recomendaciones médicas definitivas.
- Documentar las limitaciones.
- Mantener las recomendaciones dentro del alcance de bienestar general.
