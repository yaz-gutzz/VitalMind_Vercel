# Reportes de clasificación

Esta carpeta contiene los resultados de los modelos utilizados para clasificar el nivel de riesgo.

## Contenido esperado

- Accuracy.
- Precision.
- Recall.
- F1-Score.
- ROC-AUC.
- Matrices de confusión.
- Curvas ROC.
- Importancia de variables.
- Comparaciones entre clasificadores.
- Interpretación de errores.

## Reglas

- Indicar la versión del modelo.
- Indicar el conjunto evaluado.
- Documentar la distribución de clases.
- Explicar falsos positivos y falsos negativos.
- No utilizar únicamente Accuracy para seleccionar el modelo.
