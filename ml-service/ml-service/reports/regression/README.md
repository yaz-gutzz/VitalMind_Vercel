
# Reportes de regresión y pronóstico

Esta carpeta contiene los resultados de los modelos utilizados para estimar la evolución del bienestar.

- MAE.
- MSE.
- RMSE.
- R².
- Comparación de valores reales y predichos.
- Gráficas de residuos.

- Comparación entre modelos.
- Análisis de errores.

## Reglas
