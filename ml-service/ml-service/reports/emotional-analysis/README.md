# Reportes de análisis emocional

Esta carpeta contiene los resultados del modelo encargado de analizar el tono emocional de los mensajes.

## Contenido esperado

- Clases emocionales.
- Precision.
- Recall.
- F1-Score.
- Matriz de confusión.
- Ejemplos anonimizados.
- Errores frecuentes.
- Casos ambiguos.
- Limitaciones del modelo.

## Reglas

- No utilizar textos con información identificable.
- No presentar el resultado como diagnóstico psicológico.
- Documentar posibles sesgos.
- Explicar que el resultado es una estimación.
